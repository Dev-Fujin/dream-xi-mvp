# World XI Dice MVP

A mobile-first football draft game inspired by the idea of rolling historic national squads, picking one player at a time, and simulating a cup run.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- ESLint

## Gameplay

1. Pick a tactical style.
2. Draw a squad and choose eligible players for open positions.
3. Complete the XI.
4. Simulate a 7-match tournament using weighted attack/defense ratings and Poisson goal generation.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
